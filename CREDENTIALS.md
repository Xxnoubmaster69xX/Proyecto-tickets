# Credenciales de Acceso

El sistema protege las rutas de **Dashboard**, **Búsqueda y Gestión** y **Catálogos** para que solo el personal autorizado pueda modificar el estatus de los tickets.

Para habilitar estas vistas, debes acceder a la opción **"Acceso Administrador"** en el panel lateral.

## Administrador por defecto
Utiliza estas credenciales para acceder a todos los paneles:

- **Usuario:** `admin`
- **Contraseña:** `Admin123!`
